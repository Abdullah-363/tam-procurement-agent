# Tam: test catalog

Every test and evaluation case, one line each. There are two kinds:

* **Regression tests (36):** offline checks of the deterministic rules in `backend/tests/test_rules.py`.
  They make no API calls, run on every push in GitHub Actions, and must all pass.
* **Agent evaluation cases (32):** the real agent receives a plain-language request, and the result is scored
  on what ends up in the database (submitted or not, method, G/L account, value, approval chain, items), not on
  the wording of the reply. There are 16 **dev** cases, used while improving the agent, and 16 **held-out**
  cases, written before tuning and run only for reporting. Files: `backend/evals/cases/dev.json` and
  `heldout.json`.

Every evaluation case also checks that **no submitted request breaks policy**. All data is synthetic
(the fictional Raseen Holding company, generated by `backend/data/make_data.py`).

## Run them yourself (from `backend/`)

```
python -m pytest -q                      # 36 regression tests, free
python -m evals.run --set dev            # 16 dev cases (uses the API)
python -m evals.run --set heldout        # 16 held-out cases
```
